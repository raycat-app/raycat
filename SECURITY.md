# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue. Сообщите приватно через
[GitHub Security Advisories](https://github.com/raycat-app/raycat/security/advisories/new)
(вкладка Security → Report a vulnerability).

Опишите уязвимость, условия, при которых она проявляется, и, если можете, шаги
для воспроизведения. Не присылайте настоящие ссылки подписок и ключи.

Мы подтвердим получение в течение трёх дней, согласуем с вами сроки исправления
и раскрытия и укажем вас в описании исправления, если вы не против.

## Поддерживаемые версии

Исправления безопасности выходят для последней стабильной версии.

## Что считается уязвимостью

Например: трафик или DNS-запросы уходят мимо VPN при включённом kill switch;
утечка ссылки подписки, ключей или идентификатора устройства в логи, ответы API
или файлы с широкими правами; выполнение кода или запись файлов по данным от
провайдера подписки; повышение привилегий через API демона.
